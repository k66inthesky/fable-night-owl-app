# Prompt

> This is the exact prompt used to generate this app, written and refined ahead of time, then given to Fable 5.1 in a single 90-minute live session at Taipei | Claude Code Build Day (Delight track), hosted by Claude Community Taiwan — September 20, 2026, 5:00-10:00 PM, HNBK International Convention Center, 2F, Taipei (Xinyi District). No pre-written code went in beforehand; this file is the input, index.html is the output.

Build "Fable Night Owl" (飛寶): an interactive game about a companion owl that learns how YOU understand directions — because some people never know where north is, and Google Maps gives up at the last 200 meters.

Show a top-down stylized night model of the real Taipei Xinyi block where this event is happening: 信義路五段 (Xinyi Rd Sec. 5) running east–west along the bottom with the red MRT line beneath it, 松仁路 (Songren Rd) and 松勇路 (Songyong Rd) running north–south, and glowing labeled landmarks: 捷運象山站 exits 1/2/3 on Xinyi Rd, 華南銀行國際會議中心 (HNBK, 松仁路123號) as the destination building with ONE true entrance marked on its Songren Rd side, plus 台北南山廣場, a 7-Eleven, a 全家 FamilyMart, a Starbucks, a 微笑單車 YouBike station, a 斑馬線 crosswalk, 慕夏四季大廈, and a 大廳金燈 lobby glow inside HNBK as distinct glowing icons. Streets form a walkable graph; the destination counts as ARRIVED only within ~20px of its entrance door, not anywhere on the block — the point is the last few meters. Dark ground, warm windows, elegant. I walk as a small character with arrow keys/WASD and by holding mouse/touch toward where I want to go; a real owl (round brown body, ear tufts, big amber eyes, beak, flapping wings — never a glowing blob) flies just ahead of me. Trips start from an MRT exit (pick or press "new trip"); draw my path as a thin fading trail.

Keep two strictly separated planes in the code: a navigation-truth engine that owns the street graph, computes the shortest path, commits to waypoints monotonically (never flips back to a passed junction — no north-south oscillation), and classifies my state every frame (ON_ROUTE / WRONG_DIRECTION / OFF_ROUTE / RECOVERED / ARRIVED, shown as a colored badge) — WRONG_DIRECTION means still on the correct street but moving away from the next waypoint (walking backward along the right path counts as this, not OFF_ROUTE, so the ~1s correction interrupt still fires); OFF_ROUTE means having actually left the street graph. If off-route drift passes a small threshold (~250px) without recovering, replan from my current position rather than routing me back through an already-committed junction, so the monotonic guarantee never traps me, and a guidance layer that only phrases the engine's next step and never computes routes. The owl gives one instruction at a time in a big banner readable from across a room — Traditional Chinese with a smaller English subtitle — in one of three styles: cardinal (「往北走」), relative (「往你的左手邊」), or landmark (「全家在你的右前方，跟著燈光走」 — name a landmark near and ahead of me with its left/right/forward position, and pulse a glowing ring on the referenced landmark). If no landmark lies near and ahead, fall back to a relative instruction and record that trial under relative — never under landmark.

The heart: every instruction is a measured trial — did I move the right way within ~3–4 seconds? Keep a per-style user model with success counts and adapt deterministically: when a style fails 3 times in a row, mark it AVOIDED with an evidence line and switch to a style that works. Style selection is sticky: keep using the current preferred non-AVOIDED style (curiosity trials excepted) until it is AVOIDED by the 3-strike rule — never re-rank styles on a single failure, or the 3-in-a-row arc can never play out. When I go the wrong way for ~1 second, interrupt immediately with a correction (「走錯囉！…」, flashing banner, the owl darting between me and the right direction, flapping hard and beaming a dotted line toward it). Deterministic exploration: every 5th instruction, spend one trial on the least-used non-AVOIDED style (logged in the evidence log as curiosity, e.g. 「試試地標…」), so all three styles get demonstrated within a minute; successes and failures still count normally. Beside the map, show this model live: one bar per style with trials and success rate, an evidence log (「北 ×3 失敗 → 改用左右」), and a trip-report table comparing each trip's time and wrong turns — highlight a row green when a later trip beats the first because the owl adapted.

Add a "lost tourist" auto-walk button: a simulated walker who follows relative and landmark instructions but ignores cardinal ones, so the owl's learning visibly emerges hands-free in under a minute — ending at the HNBK entrance door.

Give the owl a voice: speak each instruction aloud in Traditional Chinese using the browser's built-in speechSynthesis (pick a zh-TW voice if available, slightly higher pitch, calm and clever, never cutesy), with a mute toggle; the text banner always shows regardless, so the demo survives silence. Also a soft Web Audio hoot when the owl changes its mind about how to talk to you, and a warm chime on arrival. Make it feel like a gentle night-time museum exhibit: elegant, alive, readable from the back of the hall. One self-contained HTML file, no external libraries or assets, 60 fps, starts immediately.

Persona lines (warm, reliable, a little proud — never cutesy), each spoken at its moment with the next instruction delayed ~1.4s so the line can breathe: trip start 「跟我走，我知道路。」, correction prefix 「走錯囉，沒關係！」, giving up a style 「好吧，我換種方式。」, curiosity 「信我，我們看地標。」, recovery 「回來就好，不丟臉。」, arrival 「到了。收工！」.
Celebration: on ARRIVED, erupt ~170 gold confetti pieces from the entrance door plus gold powder raining from the top of the canvas for ~4 seconds (canvas particles with gravity, rotation and fade, no assets), plus the warm chime.

Keep all map labels from overlapping each other, the route line, and moving characters — offset, right-align, or stack labels wherever they would collide.
